# 02 — Add the Conversion and Sequence Functions

**What to build:** The reference gains a Conversion group and a Sequence group, each Function with a worked example and its written result.

**Blocked by:** 01 — Open on a Function reference, starting with the Arithmetic Functions.

**Status:** ready-for-agent

- [ ] Conversion: `.^` (Number to Note) and `.v` (Note to Number).
- [ ] Sequence: `:-`, `:#`, `:<`, `:&`, `:?`, `:=`. A Sequence operand is supplied by a nested Function, for example `:<:-0104` over `04030201`.
- [ ] A Sequence result that spans more than one Sector stays inside its column.
- [ ] One example shows a Pervasive Arithmetic Function applied elementwise to a Sequence.
- [ ] The one-Tick test covers both groups.
