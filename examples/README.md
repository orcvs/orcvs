# Examples

Each example is a Source File with a guide beside it. Open any of them from
**Help > Examples** in the console, or on the site at
`/play/?example=<link-name>`. An example's link name is its name in lowercase
with a hyphen for each space, so Kombine opens at `/play/?example=kombine`.

| Example | Source File | Guide | What it plays |
| --- | --- | --- | --- |
| Beat | [beat.orcvs](beat.orcvs) | [beat.md](beat.md) | One bar of the basic 4/4 808 beat on the Built-in Synth's kit. |
| Melody | [melody.orcvs](melody.orcvs) | [melody.md](melody.md) | A row of eight Notes you edit where they stand. |
| Tracker | [tracker.orcvs](tracker.orcvs) | [tracker.md](tracker.md) | Learn Orca's eight-voice tracker, playing the 808 beat and an acid bassline. |
| Sequencer | [sequencer.orcvs](sequencer.orcvs) | [sequencer.md](sequencer.md) | Learn Orca's ten-voice sequencer, playing the 808 beat and an acid bassline over two bars. |
| Knobs | [knobs.orcvs](knobs.orcvs) | [knobs.md](knobs.md) | An acid bassline with knobs sweeping the voice and its effects. |
| Kombine | [kombine.orcvs](kombine.orcvs) | [kombine.md](kombine.md) | Three pitches against four velocities. |
| Presets | [presets.orcvs](presets.orcvs) | [presets.md](presets.md) | An acid bassline whose cutoff and resonance slew between two presets. |
