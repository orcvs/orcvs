# Separate Source interpretation from the Playback Engine

Timing, ordering, and Bang-lifetime clauses below are superseded where they conflict with [ADR 0032](0032-schedule-tick-execution-by-dependency.md). Other decisions remain in force.

Source interpretation produces a deterministic Tick Plan and commits its Source writes before handing the ordered Play Commands to the Playback Engine for that same Tick. [ADR 0032](0032-schedule-tick-execution-by-dependency.md) makes admitted writes visible to later turns during planning; atomic commit does not require frozen intra-Tick reads. The Playback Engine owns playback timing, lifecycle, and output adapters, but never parses Source or infers musical intent: it dispatches every raw Play Command exactly as supplied and schedules Note Off only where a Play Command explicitly carries a Tick lifetime, which Timed Play and Monophonic Play both do. This seam preserves deterministic interpretation and testing while preventing musical interpretation and external-delivery concerns from leaking into the Source module; all-notes-off on Playback stop or adapter disconnect remains the transport-safety exception.
