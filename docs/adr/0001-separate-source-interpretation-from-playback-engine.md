# Separate Source interpretation from the Playback Engine

Source interpretation produces a deterministic Tick Plan and commits its Source writes before handing the ordered Play Commands to the Playback Engine. The Playback Engine owns playback timing, lifecycle, and output adapters, but never parses Source or infers musical intent: it dispatches every raw Play Command exactly as supplied and schedules Note Off only when a Timed Play Command explicitly includes a Tick lifetime. This seam preserves deterministic interpretation and testing while preventing musical interpretation and external-delivery concerns from leaking into the Source module; all-notes-off on Playback stop or adapter disconnect remains the transport-safety exception.
