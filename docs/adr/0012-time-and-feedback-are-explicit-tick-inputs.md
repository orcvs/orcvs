# Time and feedback are explicit Tick inputs

Clock, delay, and Euclidean Functions adapt Orca's established formulas using the current Tick as an interpretation input, hexadecimal Numbers, and first-class Bang results; zero divisors produce diagnostics. Increment and interpolation read their previous visible result through the ordinary result Portal in the current Source Snapshot, producing a diagnostic when the expected Atom is absent, so cross-Tick behaviour remains Source-visible rather than hidden Interpreter state.
