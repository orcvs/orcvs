# Time and feedback are explicit Tick inputs

Clock, Delay, and Euclidean Functions adapt Orca's established formulas using the current Tick as an interpretation input, numeric Atoms, and first-class one-Tick Bang results. The first Playback Tick is absolute Tick `0`, and each subsequent Tick increments that unsigned counter by one. They accept Numbers and Notes interchangeably and calculate from their underlying unsigned values. Clock `~. rate modulus` returns `floor(Tick / rate) % modulus`: rate is the number of Ticks per step, modulus is the number of steps, and their product is the complete cycle length. Its value result follows the ordinary sticky-Note rule. Delay `~* rate modulus` Bangs exactly when `Tick % (rate * modulus) == 0`, including Tick `0`. Thus modulus `01` Bangs once per `rate` Ticks rather than every Tick. A zero rate or modulus diagnoses, and the cycle product is calculated in a wider integer without byte wrapping.

Euclidean `~% hits steps` uses Orca's bucket distribution and phase. At absolute Tick `t`, it Bangs when `((hits * (t + steps - 1)) % steps) + hits >= steps`. Zero hits produces no Bangs, equal hits and steps Bangs every Tick, zero steps diagnoses, and hits greater than steps diagnoses. Euclidean's numeric operands follow ordinary Sequence broadcasting; each broadcast element applies the formula independently at the same Tick.

Increment `~+ step modulus` and Interpolation `~> rate target` read their previous visible numeric Atom through the ordinary result Portal in the current Source Snapshot, treating an empty Portal as the initial Number `00` and diagnosing any other present Language Unit. Increment returns `(previous + step) % modulus` and diagnoses a zero modulus. Interpolation returns `min(previous + rate, target)` when below the target, `max(previous - rate, target)` when above it, and the unchanged target when equal; rate `00` intentionally holds the current value. Each value result follows the ordinary sticky-Note rule across its explicit operands and previous visible result.

Increment and Interpolation are scalar exceptions to pervasive Sequence broadcasting. Their explicit operands and prior visible result must each be one Number or Note; a Sequence operand or prior Sequence diagnoses. This keeps their complete cross-Tick state visible as exactly one Atom rather than inventing hidden element identity, resize, or stale-tail state.
