# Use distinct raw and timed Play Functions

Orcvs provides Raw Play as `!> channel velocity note` and Timed Play as `!~ channel velocity note length`. Both are terminal Functions activated by a Bang landing on their root, including a Bang sent by a Directional Bang Function. Separate names keep each prefix Function's arity fixed and explicit rather than making length optional or overloading one spelling. Raw Play leaves Note Off under explicit Source control through velocity `00`; Timed Play places its complete lifetime in the Tick Plan so the Playback Engine can schedule the corresponding Note Off without inferring musical intent.

For Raw, Timed, and Monophonic Play, channel is a Number in `00`–`0F`, velocity is a Number in `00`–`7F`, and note is a Note. Timed and Monophonic length is a Number in `00`–`FF`. Missing, mistyped, or out-of-range operands diagnose and emit no MIDI output. A caller with a MIDI Number uses the explicit `.^` conversion; Play does not infer a Note. These Functions send direct MIDI values without Orca's base-36 scaling or clamping.

A Timed command with velocity `00` explicitly stops the specified note in Tick Plan order and schedules no expiry, regardless of length. With nonzero velocity, length `00` emits no MIDI output: a note with zero lifetime never starts. A nonzero-velocity command produced at Tick `T` with positive length `N` starts in its Tick Plan order and schedules Note Off at the beginning of executed Tick `T + N`, before that Tick's new Play Commands. A new Timed command for the same adapter, channel, and note stops the prior Timed-owned instance before starting the replacement and invalidates the prior scheduled expiry. Raw notes do not enter Timed ownership.

The MIDI subset of the Terminal Output family also includes Monophonic Play `!%`, Control Change `!c`, and Pitch Bend `!b`. Every MIDI terminal Function accepts direct hexadecimal MIDI data, validates protocol ranges, and never applies Orca's base-36 scaling, wrapping, or clamping.

Control Change has the fixed contract `!c channel controller value`. All three operands are Numbers. Channel accepts `00`–`0F`; controller and value accept `00`–`7F`. Pitch Bend has the fixed contract `!b channel lsb msb`. All three operands are Numbers. Channel accepts `00`–`0F`; LSB and MSB each accept `00`–`7F`, exposing MIDI's wire bytes directly.

Monophonic Play has the fixed contract `!% channel velocity note length`, matching Timed Play's operand shape. The selected output adapter owns at most one Mono voice per MIDI channel. Every Monophonic command first sends Note Off for the prior Mono-owned note on that channel. Velocity `00` or length `00` then starts nothing, replacing the owned voice with silence. Otherwise it sends Note On for the replacement and schedules its Note Off at executed Tick `T + length`. Each ownership change receives a generation token; replacement invalidates the prior token so a stale expiry cannot stop the new note. Different channels are independent, and Raw Play and Timed Play notes do not enter Mono ownership. Multiple commands retain Tick Plan order, with the last command owning the channel. Playback stop, adapter disconnect, or destination change sends all-notes-off and clears Timed and Mono ownership. OSC and UDP output remain deferred until Orcvs has message and text-like values rather than encoding them as exceptional raw Source reads.
