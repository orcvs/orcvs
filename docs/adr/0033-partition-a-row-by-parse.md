# Partition a row by parse

Status: partially superseded by [ADR 0035](0035-spell-the-comment-as-a-parser-unit.md) on the Comment. The Comment paragraph below holds the rule as a byte pre-pass over `##`, run ahead of the walk; a Comment is now spelled `||` and is a Language Unit the Parser establishes, claiming every remaining Cell of its row. Wherever the text below names a Comment as a boundary an Expression's claim stops at, read ADR 0035 instead: the Parser sees the whole row, and a `||` inside a Function's arity-determined claim is an operand Cell of that Function. The partition by parse and every other decision below remain in force.

A row is divided into Expressions by the Parser rather than by its spaces. The row walk hands the Parser the row's remaining Cells together with the Cell index they begin at; the Parser reports the Cells the Expression occupies, and the walk resumes at the Cell after them. Nothing re-bases an offset against an anchor, because the Parser is reading the Grid's own Cells and reports the Grid's own addresses. This supersedes the whitespace run as a unit of partition; it does not change [ADR 0018](0018-derive-language-map-from-character-source.md)'s recovery rule, which still resumes one Cell after a spelling the Function table does not hold.

**An Expression claims what its arity declares.** A Function's signature gives its operand count and each operand's width, so `.+` with literal operands claims six Cells and `!>` eight. A nested Function fills the slot it stands in and extends the claim by its own. The Parser discovers those nested Functions while reading, so the total extent is known when that walk finishes. Its claim is confined to the available Source before the row edge or Comment; a truncated operand retains its available Cells and makes the Expression invalid.

**The row bounds parsing.** There is no separate thirty-two-record limit. A long Expression remains one Expression through its true end, and its size cannot promote nested Source into an independent root. Evaluation sizes its Operand Stack from the parsed Atom count, as recorded in ADR 0028.

**An empty Cell is a character like any other.** Between Expressions the walk skips empty Cells looking for the next anchor, and one skipped that way is neither named nor diagnosed — the space in `.=0101 !>007FC4` costs nothing. Inside a claim an empty Cell is Source that nobody has written into: the second operand of `.+01 02` is `" 0"`, which is not a Number, so the Addition is refused and the `2` after it opens the next Expression. Spacing is a matter of taste between Expressions and a matter of meaning inside one, which is what arity being the boundary amounts to.

**The row edge needs no rule of its own.** A row is as long as it is. A spelling with one Cell left to read, or an operand slot whose Cells run past the last column, is refused exactly as a spelling the table does not hold is refused — there is no reading in which Source is unfinished rather than wrong, and an Expression is either whole or invalid. Nothing is spelled across a row edge because nothing past it is there to read.

**The Comment rule survives unchanged.** Nothing at or after the first `##` in a row is Source, so the Parser is never shown it and no spelling and no claim reaches across it. The first `##` in a row is always the one the walk means, because no Language Unit spelling holds a `#`.

Trailing Source stops existing. `.+0102Z` is a complete Addition of six Cells and one invalid `Z`, not one unstable Expression; `**^^` is a Bang and a Self-Banging Function rather than a four-Cell run something had to assemble; `Z.+0304` is one refused Cell and an Addition that still plays. What used to be a verdict about the Source after an Expression is now that Source's own Expression, and the guards that existed to reconcile a whitespace run with an arity claim — a reconstruction of consumed width, a check that a run's units tiled it, a filter over the slots a run could not reach — have nothing left to reconcile.
