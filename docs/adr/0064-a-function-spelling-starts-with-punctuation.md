# A Function spelling starts with punctuation

Status: accepted. Revises the operation glyphs of [ADR 0008](0008-preserve-symbolic-arithmetic-functions.md) and the canonical-form column of [ADR 0019](0019-map-orca-capabilities-onto-orcvs-language-families.md). Not yet implemented: the renaming is one sweep across the Function table, its tests, `CONTEXT.md` and the Function reference, after ADRs 0061 to 0063 are implemented.

**Every Function spelling is two Cells, and the first is a punctuation family glyph.** Data in Orcvs is letters and digits: Numbers are uppercase hexadecimal, and Notes are a pitch letter followed by an octave digit or `/`. A punctuation anchor therefore stands out in a row of data and in a nested Expression, and it can never be read as data. That contrast is what the original glyphs got right, and what lowercase letter names such as `ad` and `cl` would lose: `.x.+.+01010203` shows three Functions, but `mladad01010203` is a run of letters. The families are `.` numeric, `~` Tick and feedback, `*` activation, `&` address, `@` Source read and write, and `!` terminal output. [ADR 0063](0063-a-list-is-cells-in-a-claim-not-a-value.md) retires `:`.

**The second Cell is a universal symbol where one exists, and a mnemonic lowercase letter otherwise.** The universal symbols are `+ - x / % < > =`, for addition, subtraction, multiplication, division, modulo, minimum, maximum and equality, plus `?` for random. Every other Function takes the first letter of its name, or the letter that best names it when two Functions in one family share an initial. The letter is lowercase because lowercase never appears in that Cell of any data: hexadecimal is uppercase, and a lowercase sharp is always followed by an octave character. Second glyphs that had to be memorised, such as `~%` for Euclidean, `!%` for Monophonic Play and `~*` for Delay, become letters. Absolute difference loses `|`, which is not universal. The concrete table is settled in the renaming ticket.

**Pictogram spellings stay as they are:** the Bang `**`, the Comment `||` and the movers `^^ vv << >>`. They draw what they do, and the movers echo Befunge's arrows. `vv` is the one spelling made of letters, and it is the named exception to the punctuation rule.

## Considered options

The glyph pairs as they stand keep the contrast but leave many second glyphs arbitrary. Two lowercase letters are the easiest to read aloud but lose the contrast. A family glyph followed by Orca's uppercase letter keeps the Orca lineage, but `A` to `F` are hexadecimal digits, so `~C0108` starts to read as data, and the uppercase letter brings back the scheduling signal ADR 0019 left behind. Unicode glyphs read best but need a different Cell representation, a non-ASCII Source File and an input method that suits live performance.
