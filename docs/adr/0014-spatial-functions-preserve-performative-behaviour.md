# Spatial Functions preserve performative behaviour

Orcvs retains Orca's playful spatial movement, collision, jumper, and halt capabilities rather than treating them as obsolete routing workarounds. Initial movement Functions atomically move their complete Expression by one Cell when a Bang lands on their root or a directional Always Function targets them; a blocked move leaves the Expression intact and emits a collision Bang. Horizontal and vertical jumper chains carry whole Patterns through visible Portal chains, while an activated Halt suppresses a target Expression for the current Tick through a pre-evaluation control phase resolved from the same Source Snapshot.
