# Directional Bang and Jump preserve performative spatial behaviour

Orcvs represents visible directional motion with the root-only Self-Banging Functions `^^`, `vv`, `<<`, and `>>`. A Directional Bang Function emits the matching spelling into Source. The emitted Function first receives a turn from the next Source Snapshot, intrinsically receives Bang activation at that turn, and advances its complete two-Cell Span by one Cell.

Movement is one validated Portal effect bundle. It tests only newly entered Cells, ignoring overlap with the current Span. An empty destination emits spaces over the current Span before writing the same Function spelling at the shifted destination; ADR 0020's emission order makes the shifted spelling win at a shared horizontal Cell. A blocked or out-of-Grid move writes `**` over the current Span. Complete aligned root contact also delivers Bang activation; partial Language Unit contact diagnoses and delivers nothing. The Function spelling keeps direction and all cross-Tick state visible in Source.

The Address family provides four directional Jump Functions: `&^`, `&v`, `&<`, and `&>`. Orca provides only the vertical Jumper and horizontal Jymper forms. Orcvs makes all four directions explicit. A Jump relays a copy of exactly one complete aligned two-Cell Language Unit. It does not slice an arbitrary character from a Span, and it does not transport a Sequence.

A chain contains one or more directly consecutive Jump Functions with the same directional spelling. The head is the member adjacent to the input, opposite the travel direction, and only that head relays; every later member sees the preceding same Jump and produces no effect. Horizontal members have touching two-Cell Spans with anchors two columns apart. Vertical members have the same anchor column on adjacent rows. A gap, misalignment, or different spelling ends the chain.

For east, the head input anchor is two columns west of the head and output anchor is two columns east of the tail. For west, input is two columns east of the head and output is two columns west of the tail. For north, input is one row south of the head and output is one row north of the tail. For south, input is one row north of the head and output is one row south of the tail. All vertical input and output anchors retain the chain's column.

A completely empty aligned two-Cell input clears the aligned two-Cell destination. A partial, misaligned, or invalid input diagnoses and writes nothing. An ordinary non-Bang Language Unit atomically overwrites the complete two-Cell destination, including occupied Source; an out-of-Grid destination diagnoses and receives no partial write. A Jump chain uses its head anchor as its producer Position, and all effects follow ADR 0020's producer-anchor and emission order. A copied Function first becomes actionable from the next Source Snapshot.

A Jump relays Bang through its output Portal rather than applying ordinary overwrite. Bang landing on an Expression root activates it without changing its Source when the target's turn has not passed; an earlier target is not revisited. Bang landing on a completely empty destination writes `**` for its ordinary one-Tick Source life. Bang landing on an occupied non-root or leaving the Grid diagnoses and writes nothing.

Every Jump reads only the Source Snapshot. A relayed Bang may activate another later root, including another Jump, in the same Tick. That root reads its own Snapshot input rather than planned writes. Every root has one turn, so backward routing and cycles stop at a root whose turn has passed. Ordinary planned writes do not become inputs or executable code during the same Tick. More complex Cell addressing remains deferred.

Halt `*!` is an Activation Function. When active at its turn, it locks the Expression root whose anchor Position is one row directly south before that root's later turn. An empty target is a no-op, and an occupied non-root target diagnoses. Orcvs does not revisit Halt after its turn, and a suppressed Halt does not lock its own target.
