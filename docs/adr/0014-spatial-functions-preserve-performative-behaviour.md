# Directional Bang and Jump preserve performative spatial behaviour

Orcvs does not retain Orca's self-moving Operator as a separate Function family. Directional Bang Functions provide the related performative motion: a Source-resident Activation Character uses `^^`, `vv`, `<<`, or `>>` to retain its direction and advances its complete two-Cell encoding by one Cell per Tick. A Directional Bang Function whose initial two-Cell Footprint is occupied or would leave the Grid emits nothing, remains unchanged, and diagnoses. After successful emission, movement tests only newly entered Cells, not self-overlap with the Activation Character's current Footprint. A blocked or out-of-Grid move changes that current encoding to the Bang `**`, following Orca. Complete aligned contact with an Expression root can activate it; partial contact with any Language Unit is invalid alignment, diagnoses, and activates nothing. The Tick-step motion makes travel visible and keeps cross-Tick state in Source.

The Address family provides four directional Jump Functions: `&^`, `&v`, `&<`, and `&>`. Orca provides only the vertical Jumper and horizontal Jymper forms. Orcvs makes all four directions explicit. A Jump relays a copy of exactly one complete aligned two-Cell Language Unit. It does not slice an arbitrary character from a Footprint, and it does not transport a Sequence.

A chain contains one or more directly consecutive Jump Functions with the same directional spelling. The head is the member adjacent to the input, opposite the travel direction, and only that head relays; every later member sees the preceding same Jump and produces no effect, following Orca. Horizontal members have touching two-Cell Footprints with anchors two columns apart. Vertical members have the same anchor column on adjacent rows. A gap, misalignment, or different spelling ends the chain.

For east, the head input anchor is two columns west of the head and output anchor is two columns east of the tail. For west, input is two columns east of the head and output is two columns west of the tail. For north, input is one row south of the head and output is one row north of the tail. For south, input is one row north of the head and output is one row south of the tail. All vertical input and output anchors retain the chain's column.

A completely empty aligned two-Cell input clears the aligned two-Cell destination. A partial, misaligned, or invalid input diagnoses and writes nothing. An ordinary non-Bang Language Unit atomically overwrites the complete two-Cell destination, including occupied Source; an out-of-Grid destination diagnoses and receives no partial write. Tick Plan write conflicts retain the head's Source-order position, and a copied Function or Activation Character becomes active only from the next Source Snapshot.

A Jump relays Bang through its output Portal rather than applying ordinary overwrite. Bang landing on an Expression root activates that Expression without changing its Source when the target's Source-order turn has not passed; an earlier target is not revisited. Bang landing on a completely empty destination writes `**` for its ordinary one-Tick Source life. Bang landing on an occupied non-root destination diagnoses and writes nothing. Bang leaving the Grid also diagnoses and writes nothing.

Every Jump reads only the current Source Snapshot. A relayed Bang may activate another root, including another Jump, in the same Tick only when the target's row-major Source-order turn has not passed. That root reads its own Snapshot input rather than planned writes. Every root has one turn, so backward routing and cycles stop silently at a root whose turn has passed. Ordinary planned writes do not become inputs or executable code during the same Tick. More complex Cell addressing remains deferred.

Halt `*!` is an Activation Function. When active at its Source-order turn, it locks the Expression root whose anchor Position is one row directly south before that root's later turn. An empty target is a no-op, and an occupied non-root target diagnoses. Orcvs does not revisit Halt after its turn, and a suppressed Halt does not lock its own target. This preserves Orca's top-to-bottom ordering without a separate control phase.
