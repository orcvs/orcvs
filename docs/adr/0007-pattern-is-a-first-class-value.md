# Pattern is a first-class language value

Functions may return a flat ordered Pattern of multiple Atoms rather than representing every multi-Cell capability as terminal Source writes. Atomic Functions extend pervasively across compatible Patterns: an Atom is repeated across a Pattern, two equal-length Patterns pair element-wise, and incompatible non-scalar lengths diagnose; Pattern-specific Functions transform the sequence itself. An ordinary Pattern result encodes horizontally from the Expression's ordinary result Position through one Portal carrying the intact Pattern; if its complete encoding cannot fit, interpretation reports a diagnostic and plans no partial write. Successfully encoded Cells become ordinary Source content under the same parsing, diagnostic, atomic-write, and generated-code rules as a single Atom, without a privileged literal-Pattern interpretation.
