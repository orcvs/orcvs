# A blank operand gives a blank answer

Status: accepted. Clarifies [ADR 0061](0061-a-nested-function-returns-to-the-slot-it-occupies.md)'s Return for a blank operand, and amends the nested-consumer failure clause of [ADR 0034](0034-execute-against-live-typed-expressions.md) and the absent-result clause of [ADR 0032](0032-schedule-tick-execution-by-dependency.md) for that case. Implemented by `.scratch/cell-tracker/issues/03-blank-operands-clear-output-portals.md`.

**A blank answer is two spaces.** The glossary calls it the Blank Answer. It is what a value Function answers when one of its inline input portals is blank, and it is delivered like any other answer: the Function writes the two spaces through its Output Portal, and when it is nested its Return is those two blank Cells. Blankness therefore travels one way, whether it arrives at a slot through nesting or through a Portal, and the slot that receives it is blank in turn.

**An inline input portal whose Cells are all empty makes its value Function give a blank answer, without a diagnostic.** A Terminal Output Function with a blank operand emits no command. A Bang still activates the Function, and it still gives a blank answer. A portal with some Cells empty and others not, such as the `" 0"` in `.+01 02` that [ADR 0033](0033-partition-a-row-by-parse.md) describes, is malformed and diagnoses as before. Blank operands still occupy the claim, because a claim is the arity and not the content.

A blank operand is ordinary content, not an error. Clearing a slot is something a performer does by hand and a Portal does by writing spaces ([ADR 0009](0009-portals-resolve-tick-plan-destinations.md)). A blank Item a Track (`@t`) copies into Timed Play's note slot is a rest ([ADR 0063](0063-a-list-is-cells-in-a-claim-not-a-value.md)). Treating each of these as a fault would fill the diagnostics with silence that was intended, and it would hide the malformed operands that diagnostics exist to report. Orca reads blank differently: an empty port reads as `0` or the port's default, so its arithmetic operators and Clock run on zero and write every frame, Track copying an empty Cell writes `.` and so clears its output, and only MIDI returns early on an empty channel, octave or note. Orcvs keeps blank as blank rather than reading it as zero; Considered options gives the reason.

**A blank answer writes, so a consumer fed through a Portal does not replay a stale value.** A value root whose Output Portal feeds Timed Play's note slot below it clears that slot when its own operand goes blank, and the Timed Play that a Bang then activates emits no Play Command. A blank answer that planned no write would leave the previous Note in the slot, and the next Bang would play it again. A nested blank Return makes the enclosing value Function give a blank answer too: it writes spaces at its own Output Portal and returns blank to its parent.

**The Absence Marker is not blank.** Equality with unequal operands, and Delay or Euclidean on a Tick they do not fire, answer the Absence Marker, which keeps its existing meaning: no write, so the destination keeps its characters, and no activation. This decision gives the Absence Marker no Source encoding and does not turn it into a blank answer. Only an all-empty inline operand, a blank Return or Portal write that leaves one, a Jump copying two spaces, or a Track (`@t`) selecting a blank Item produces a blank answer. A nested Function that answers the Absence Marker therefore still returns nothing, and its parent diagnoses the missing Return under ADR 0034's nested-consumer failure clause, which this decision amends only for a blank Return. The Blank Answer and the Absence Marker are kept apart in the implementation for the same reason: the Blank Answer is not an Atom, so no Function takes it as an operand, and the Absence Marker never plans a write.

**A blank operand is complete Source.** The Parser reads a slot whose Cells are all spaces as a complete operand that holds no Atom, so the Language Map reports nothing for it and the Expression is a root. Source Paint still shows the slot as a pending operand. This holds when every operand is blank: a freshly typed `.+` is a complete root that gives the Blank Answer.

**A Jump that copies a blank gives a blank answer.** A Jump whose aligned input is two spaces already cleared its destination. That clear is the Blank Answer, so a nested Jump returns blank to its parent rather than nothing, and blankness reaches the parent the same way whether a Jump writes it spatially or returns it.

## Consequences

A value Function clears its Output Portal as soon as it is typed and reserves those Cells while its operands are blank. A freshly typed `.+` gives the Blank Answer, so the two Cells south of it become spaces before any operand is written. Exempting the case where every operand is blank would not protect those Cells, because typing an operand passes through one-blank states such as `.+01`, which clear under either rule. Orca likewise writes as soon as an operator is typed.

A blank answer from a Function whose Output Portal is also its input clears its state. A blank operand to Increment or Interpolation writes spaces over the feedback Cell they share with their output, and on the following valid evaluation they read the cleared Cell as their initial `00`, so the count or glide restarts. A performer who blanks an operand for one Tick loses that state; keeping it would need a no-write exception for exactly the Functions whose Output Portal is an input, the exception [ADR 0061](0061-a-nested-function-returns-to-the-slot-it-occupies.md) declines for nesting.

## Considered options

**Read a blank operand as zero, as Orca does.** Rejected. Under zero a rest survives a copy, so a Track feeding Timed Play still rests, but it becomes a note as soon as arithmetic touches it: a transposed tracker `.+@t…0C` plays `0C` at every rest. User story 17 of `.scratch/cell-tracker/spec.md` requires a blank slot to stay blank through nested expressions. Reading zero for Numbers and blank for Notes reintroduces the same fault, because a returned Note enters `.+` as a Number under [ADR 0061](0061-a-nested-function-returns-to-the-slot-it-occupies.md).

**Treat an Expression whose every operand is blank as incomplete.** Rejected. It would restore a diagnostic and withhold the write only for the bare spelling `.+`; the one-blank states typing passes through next clear the Output Portal anyway, so the exception protects no Cells and adds a second rule for blank operands.

**Give a Jump copying two spaces the Absence Marker.** Rejected. A root Jump writes spaces for empty input, so answering the Absence Marker would write spaces south yet return nothing, breaking ADR 0061's rule that a Return is the same encoding the Function writes, and contradicting the Absence Marker's rule that it plans no Cell write.
