# Defer Source addressing for an infinite canvas

Orcvs may evolve from its current finite Grid into a sparse infinite canvas, so the Orca Function audit will not prescribe relative offsets, two-digit absolute coordinates, or a 256×256 Source limit. Spatial capabilities remain in scope behind an unresolved Cell-addressing mechanism, while non-spatial Functions may proceed independently and the console's 32×32 default remains an exploratory size rather than an address-space contract.
