# Use distinct Range Functions and two-Cell Comments

Status: partially superseded by [ADR 0035](0035-spell-the-comment-as-a-parser-unit.md) on the Comment. The introducer is spelled `||` and a Comment is a Language Unit the Parser establishes rather than text removed ahead of the walk; one `|` alone is incomplete or invalid Source, exactly as one `#` was. The Range Function decisions and Sequence clauses are superseded by [ADR 0063](0063-a-list-is-cells-in-a-claim-not-a-value.md). The rule that made ADR 0021's conversion Functions the "sole type-directed exception", passing an already-converted value through, is amended by [ADR 0061](0061-a-nested-function-returns-to-the-slot-it-occupies.md); the paragraph below states the amended rule.

Orcvs assigns `:-` to Number Range and `:#` to Note Range, giving each Function one fixed operand and result signature rather than selecting numeric or musical behavior from its operands. To make `:#` an unambiguous two-Cell Function and keep reserved Source forms aligned with the language's two-Cell recognition model, Comments begin with `##`; one `#` alone is incomplete or invalid Source. The Sequence Functions are removed by ADR 0063. A nested conversion Return is decoded by its receiving operand type under ADR 0061, then evaluated by the conversion Function; it does not preserve the child Atom's type.
