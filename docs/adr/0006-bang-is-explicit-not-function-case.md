# Bang activation replaces Function case

Orcvs does not adopt Orca's convention that uppercase Operators run every Tick while lowercase Operators require a neighbouring Bang. Bang is the two-Cell Atom `**`, and Functions have one canonical spelling. Every root Expression is inert—including time and Bang-producing Functions—until activated. For a Bang anchored at `(x, y)`, the only cardinal root anchors are north `(x, y-1)`, south `(x, y+1)`, west `(x-2, y)`, and east `(x+2, y)`; only a complete aligned Expression root at one of those anchors activates. A Portal may instead deliver Bang directly to one root without overwriting its Function Cells. Activation recursively includes the Expression's nested Functions. A Bang already present in the Source Snapshot plans removal at the current Tick's commit. A Bang generated during the Tick is written at that commit, remains visible for the next Source Snapshot, participates in that next Tick's routing, and is removed by the next commit. Direct same-Tick Bang delivery is an activation event separate from that stored glyph.

Activation scheduling follows Orca's single row-major pass. The Interpreter visits each Expression root once in row-major order of its anchor Position and tests whether it is active and unlocked at that turn. A Bang delivered during the pass can activate a root whose turn is still ahead, but no root whose turn has passed is revisited; multiple Bangs do not make a root evaluate more than once. Effect precedence remains keyed to root Source order rather than activation discovery time.

The four Directional Bang Functions `*^`, `*v`, `*<`, and `*>` replace Orca's uppercase form with visible spatial activation. Each Function emits one Activation Character Language Unit into Source in its direction: `^^`, `vv`, `<<`, or `>>`. For a Function at `(x, y)` and `(x+1, y)`, north emits at `(x, y-1)` and `(x+1, y-1)`; south emits at `(x,y+1)` and `(x+1,y+1)`; west emits at `(x-2,y)` and `(x-1,y)`; east emits at `(x+2,y)` and `(x+3,y)`. The complete Footprint starts outside the Function Footprint and advances by one Cell per Tick after emission. Movement tests only newly entered Cells, excluding overlap with the Activation Character's own current Footprint. If the initial Footprint is occupied or leaves the Grid, the Directional Bang Function remains unchanged, emits nothing, and diagnoses. A successful move atomically clears the old Footprint and writes the new Footprint. If a later move is blocked or any part of the new Footprint would leave the Grid, the current Activation Character becomes the Bang `**`, following Orca's collision rule. Complete aligned contact with an Expression root delivers Bang activation when the root's Source-order turn has not passed. Contact with only part of any Language Unit is invalid alignment: it diagnoses, blocks the move, produces `**`, and activates nothing. Complete contact with a non-root blocks and produces `**` without activation or an additional collision diagnostic. The committed `**` remains visible at the Activation Character's old Position for its ordinary one-Tick Source life. Travel state and direction remain visible in Source rather than hidden in the Interpreter. An Activation Character is not a Function.

Halt `*!` belongs to the Activation family because it prevents activation or evaluation rather than moving a value or changing an address. When Halt is active at its turn in Source order, it targets only the Expression root whose anchor Position is one row directly south of the Halt anchor. It locks that root before the later southward turn, so the complete target Expression does not evaluate and contributes no effects. Halt does not change the target Source. An empty target is a no-op. An occupied target that is not an Expression root diagnoses. Orcvs does not revisit a Halt whose turn has passed when activation reaches it later in the same Tick. A Halt suppressed by another Halt does not lock its own target. This preserves Orca's top-to-bottom ordering rather than introducing a separate Halt control phase.
