# Bang activation and Always replace Function case

Orcvs does not adopt Orca's convention that uppercase Operators run every Tick while lowercase Operators require a neighbouring Bang. Bang is the two-Cell Atom `**`, and Functions have one canonical spelling. Every root Expression is inert—including time and Bang-producing Functions—until a Bang Portal lands exactly on its root Function or a directional Always Function targets it; activation recursively includes the Expression's nested Functions without overwriting the root. A Bang participates in activation routing for exactly one Tick, after which that Tick's atomic commit removes it from Source.

The four self-scheduled Always Functions `@^`, `@v`, `@<`, and `@>` replace Orca's uppercase form with visible spatial scheduling. Each Tick, Always travels through empty Cells in its direction and activates only the first occupied Cell when that Cell is an Expression root. Any other occupied Cell blocks the path and diagnoses. The target Expression retains its own result Portal; Always schedules but produces and forwards no value. Activation routing is resolved within the same Tick Plan: a newly produced Bang may activate its target immediately, while a root targeted by any number of Bangs or Always rays evaluates at most once that Tick.
