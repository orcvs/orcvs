# Check Sequence membership at one construction point

`Sequence::new` is the single point at which a Sequence comes into being, and membership is checked there and nowhere else. `Sequence::empty`, `Sequence::promote`, and every structural Sequence Function funnel through it, so all of them inherit one rule and one diagnostic rather than repeating a check each could get wrong differently. Two Atoms are refused. A Self-Banging Function is refused because it is a root-only Source effect rather than an operand, runtime value, or Sequence member, as CONTEXT.md and ADR 0009 both state. The absence marker is refused because it is what the Interpreter answers with when an Expression leaves no value, not an Atom with a Source encoding of its own. The check is exhaustive over `Atom` rather than admitting the remainder through a wildcard, so a new Atom variant is classified at the compiler instead of becoming a legal member by default.

Orcvs does not instead make the invalid Sequence unrepresentable. A `Member` type carrying every Atom variant except those two, with `TryFrom<Atom>` at the boundary, would move the invariant to the type system and is the stronger design. Its real prize is not safety but an infallible `Sequence::new`: Reverse and Concatenate take Sequences and return Sequences, so neither can produce an invalid member, yet against a fallible constructor both must carry an error path that cannot be reached. The type is deferred rather than rejected. Nothing outside the tests calls the Atom accessor today, so its signature is still free to change; the structural Sequence Functions are the first callers, and the point at which they are written is the point at which the type earns its conversions.

The exclusion cannot be named as a property of the Atom, which is why the deferred type names a role. A Self-Banging Function has a complete Source encoding and is refused for what it does rather than for how it encodes, while the absence marker is refused for having no encoding at all. The two refusals share no property, so membership is a role the Sequence defines over Atoms and not a capability an Atom carries.
