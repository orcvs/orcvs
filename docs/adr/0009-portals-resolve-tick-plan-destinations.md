# Portals resolve Tick Plan destinations

A Portal is an internal destination resolved while interpreting one Source Snapshot, not a first-class language value or persistent state. Ordinary results and terminal Source Functions send an Atom or one intact Sequence through a Portal into planned Source writes; Tick planning expands a non-empty encoding only after complete fit validation, and a failed validation diagnoses and plans no write. An empty Sequence plans no Cell writes. A Portal writes only the supplied current encoding and never clears a stale tail outside that Footprint. Valid writes participate Cell-wise in ADR 0020's total effect order. This allows future Cell-addressing models—including an infinite canvas—to change how destinations resolve without changing Function evaluation or Tick Plan commit semantics.
