# Portals resolve Tick Plan destinations

A Portal is an internal destination resolved while interpreting one Source Snapshot, not a first-class language value or persistent state. Ordinary results and terminal Source Functions send an Atom or one intact Pattern through a Portal into planned Source writes; Tick planning expands the encoding only after complete fit validation. This allows future Cell-addressing models—including an infinite canvas—to change how destinations resolve without changing Function evaluation or Tick Plan commit semantics.
