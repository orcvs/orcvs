# General arithmetic wraps over bytes

General Orcvs Addition `.+ left right`, Subtraction `.- left right`, and Multiplication `.x left right` calculate with the operands' underlying unsigned byte values and wrap the mathematical result modulo 256 across the full `00`–`FF` Number range instead of saturating at its boundaries. Subtraction is ordered `left - right`; symmetric Absolute Difference `.| left right` returns `abs(left - right)`. Division `./ left right` returns the unsigned integer quotient `floor(left / right)`. Division by zero has no cyclic interpretation, so it produces a diagnostic and no result rather than inventing a Number.

Numbers and Notes are interchangeable operands in every numeric Function and in either operand position. If any operand is a Note, a value-producing Function returns a Note and wraps modulo 128 across the complete MIDI note range. If every operand is a Number, it returns a Number and wraps modulo 256. Bang-producing Equality still returns Bang. Every value result remains Source-round-trippable through two-Cell notation: uppercase pitch letters are naturals, lowercase pitch letters are sharps, `/` denotes the octave below zero, and decimal octave glyphs cover zero through nine, giving `C/` for MIDI `00` through `G9` for MIDI `7F`. Orcvs requires no conversion Function between Number and Note arithmetic.

Modulo `.% left right` returns the unsigned remainder `left % right` and diagnoses when the right operand is zero. Minimum `.< left right` returns the smaller underlying value, and Maximum `.> left right` returns the larger underlying value. Equality `.= left right` compares underlying values: equality produces one Bang, while inequality produces no value and plans no result write. These Functions use the same interchangeable Number and Note operand rule and the ordinary pervasive Sequence-broadcasting rule; each broadcast element either produces its value or Bang independently.
