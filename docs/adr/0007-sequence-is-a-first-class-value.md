# Sequence is a first-class language value

Functions may return a flat ordered Sequence of multiple Atoms rather than representing every multi-Cell capability as terminal Source writes. Sequence is the canonical term because the value has order but no inherent repetition, rhythm, or pattern structure. Stateless Atomic Functions extend pervasively across compatible Sequences: an Atom is repeated across a Sequence, two equal-length Sequences pair element-wise, and incompatible non-scalar lengths diagnose; Sequence-specific Functions transform the sequence itself. Stateful feedback Functions may explicitly remain scalar when element identity would otherwise require hidden cross-Tick state. An ordinary non-empty Sequence result encodes horizontally from the Expression's ordinary result Position through one Portal carrying the intact Sequence; if its complete encoding cannot fit, interpretation reports a diagnostic and plans no partial write. It writes exactly its current encoding and never infers or clears Cells beyond that Footprint from an earlier, longer result. An empty Sequence plans no Cell writes. Successfully encoded Cells become ordinary Source content under the same parsing, diagnostic, atomic-write, and generated-code rules as a single Atom, without a privileged literal-Sequence interpretation.

Range `:-` takes two bounds of the same ordinal Atom type and returns an inclusive Sequence with a unit step. Number bounds step through byte values. Note bounds step chromatically through MIDI note values while preserving Note identity. Bound order selects ascending or descending output, and equal bounds return a singleton Sequence. Mixed Number and Note bounds diagnose, as do Bang, Function, and Activation Character bounds. Range output retains the ordinary complete-fit Portal rule and never writes a partial Sequence.

Reverse `:<` reverses only the Atom order of one Sequence. It preserves each Atom's complete encoding and type. A singleton remains unchanged, and an empty Sequence remains empty.

Concatenate `:&` accepts an Atom or Sequence for each operand. It promotes an Atom to a singleton Sequence and returns the left operand's Atoms followed by the right operand's Atoms, preserving each Atom's type and complete encoding. Output is always flat because Sequences cannot nest. An empty Sequence is the identity. Concatenate output retains the ordinary complete-fit Portal rule and never writes a partial Sequence.

Select `:?` takes one Number index and one non-empty Sequence and returns one Atom with its type and encoding preserved. Index `00` selects the first Atom, and other indices wrap modulo Sequence length, preserving Orca Track's cycling behavior. An empty Sequence diagnoses. A Note or Sequence index also diagnoses; Select does not broadcast or return a subsequence.

Replace `:=` takes a Number index, one replacement Atom, and one non-empty Sequence. It returns a new Sequence of the same length with the indexed Atom replaced and leaves the input Sequence unchanged. Indexing is zero-based and wraps modulo Sequence length like Select and Orca Push. The replacement may have a different Atom type. An empty Sequence, non-Number index, or Sequence replacement diagnoses.
