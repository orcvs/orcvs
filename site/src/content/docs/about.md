Orcvs is an internal, pre-release application. The language is still being designed, so spellings
and behaviour change without a compatibility promise, and this site follows the repository as it
changes.

The console here is the same program as the desktop console, built for the browser. The desktop
console is the primary one; it runs from a checkout with `cargo run`, as the
[README](https://github.com/orcvs/orcvs#readme) describes.

- Source code: [github.com/orcvs/orcvs](https://github.com/orcvs/orcvs)
- What each term means: [`CONTEXT.md`](https://github.com/orcvs/orcvs/blob/main/CONTEXT.md)
- Decisions and their reasons: [`docs/adr/`](https://github.com/orcvs/orcvs/tree/main/docs/adr)
- Orcvs works in the tradition of [Orca](https://100r.co/site/orca.html).
