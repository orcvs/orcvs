Should an Orcvs Function return a Sequence?

Superseded exploration. This prototype records the comparison that led to first-class Sequences. Its hypothetical names and alternative terminal-write model do not state the current language contract. See ADR 0007 and the Orca-to-Orcvs capability map for the recorded decision.

First-class Sequence

Terminal multi-write

A multi-cell Function is an Expression-root effect and cannot supply a nested value.
