Orca and Orcvs Function Map

This document maps each Orca Operator to an Orcvs Function. It also shows the Functions that exist only in Orcvs.

Prefix families: . arithmetic, ~ time, * activation, & address, @ Source read/write, : Sequence structure, and ! terminal output. The suffix column records the earlier proposal.

Behavior details

Arithmetic and comparison

Orca

A adds two base-36 values.

B calculates the absolute difference. It does not do ordered subtraction.

F compares two glyphs.

L selects the smaller value.

M multiplies two values.

Orcvs

Orcvs uses byte Numbers.

Orcvs separates ordered subtraction from absolute difference.

Orcvs has Division. Orca does not have this Operator.

Numbers and Notes are interchangeable numeric operands.

Any Note operand makes a value result a Note.

Note results wrap modulo 128.

Number results wrap modulo 256.

Time, rhythm, and feedback

Orca

C reads the current frame.

D makes a Bang at a frame interval.

I reads and changes its south output Cell.

R uses hidden random state.

U makes a Euclidean rhythm.

Z moves its south value towards a target.

Orcvs

Clock, Delay, and Euclidean read the Tick.

Increment and Interpolation read their prior visible result.

Random uses an explicit seed.

Random gives the same result for the same Source Snapshot and Tick.

Move

Orca

E, N, S, and W move their own Operator glyph.

Each move has a distance of one Cell.

A blocked Operator replaces itself with a Bang.

Orcvs

Orcvs does not have a separate Move Function.

An Activation Character occupies two Source Cells.

^^, vv, <<, and >> retain its direction.

The complete encoding advances by one Cell per Tick.

A blocked or out-of-Grid move changes it to **.

An occupied collision target receives the Bang activation in the same Tick.

Unrelated neighbours do not receive it.

This follows Orca's collision rule.

Jump and Halt

Orca

J reads one glyph immediately north.

J writes the glyph below a vertical chain of J Operators.

Y reads one glyph immediately west.

Y writes the glyph after a horizontal chain of Y Operators.

H stops the Operator in the Cell immediately south.

Orcvs

The Address family uses the & prefix.

Orcvs has Jump Functions for north, south, west, and east.

A chain copies one complete adjacent Language Unit to the Cell beyond the final Jump.

More complex Cell addresses are deferred.

Halt *! is an Activation Function.

Source read, write, and selection

Orca

O reads one glyph at an offset.

X writes one glyph at an offset.

G copies a group of eastward glyphs to an offset.

Q reads a group of glyphs at an offset.

T selects one eastward glyph.

P writes one glyph to a selected output Cell.

K reads values from the Variable table.

V reads or writes the hidden Variable table.

Orcvs

Query becomes Source Read returning one Sequence.

Generate becomes Source Read followed by Source Write.

Track becomes Sequence Select.

Push becomes Sequence Replace followed by Source Write.

Konkat becomes Source Read from visible Source.

Orcvs does not use a hidden Variable table.

Orcvs keeps persistent state in Source.

The Source address form is deferred.

Activation

Orca

An uppercase Operator runs on each frame.

A lowercase Operator runs when it is next to a Bang.

A Bang has a life of one frame.

Orcvs

Each Function has one form.

A Bang can activate a root Function.

A directional Bang Function emits a traveling activation character.

The character becomes a Bang when it reaches an occupied Cell.

Halt belongs to this family.

MIDI output

Orca

: sends a MIDI note.

The operands include an optional note life.

% stops the prior note before it sends the next note.

! sends a MIDI control change.

? sends two pitch-bend bytes.

Orcvs

Raw Play sends a note without a note life.

Timed Play sends a note with a Tick life.

Monophonic Play owns one note per adapter and channel.

Control Change and Pitch Bend use direct hexadecimal MIDI bytes.

Messages and host control

Orca

; sends eastward glyphs as a UDP message.

= sends an OSC path and message.

$ sends a command to the Orca host.

Orcvs

UDP !u and OSC !o are deferred.

Orcvs needs a text or message value first.

Application Command !$ sends only to the application's explicit command dispatcher.

It never invokes a shell or arbitrary executable.

Its command value encoding is deferred.

Orcvs value and interpretation model

Orca

Most values use one base-36 glyph.

An Operator usually writes directly to an output Cell.

Group Operators read or write separate Cells.

Orcvs

A Number uses two hexadecimal Cells.

A Note uses two Cells.

A Sequence is a flat group of Atoms.

A Portal identifies a planned destination.

A Tick Plan contains all Source changes and output commands for one Tick.

Sequence Functions operate on complete Language Units.
