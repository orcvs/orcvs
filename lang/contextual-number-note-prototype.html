THROWAWAY SYNTAX PROTOTYPE

Literal characters receive type from their Function

Source stores characters. A literal occurrence becomes exactly one Atom only after its Expression is parsed against a fixed Function signature. The spelling C4 is therefore Number 196 under :- and Note 60 under :# or !>; this is contextual interpretation, not implicit conversion.

Complete canonical Note mapping

Pitch letters are uppercase for naturals and lowercase for sharps. / is the octave below 0. The generated table contains exactly MIDI 00 through 7F; each Note has one two-Cell spelling in a Note operand position.
